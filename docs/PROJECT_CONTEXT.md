## Architecture map
- `lib/main.dart` (~2,841 lines): app entry, TV UI, V2Ray status, profiles/accounts, update download/install, ping, server selection, connection/recovery, Albania/YouTube route.
- Central types: `TvServer`, `TvPhase`, `TvRoot`, `_TvRootState`.
- Connection lifecycle: `_onStatus`, `_scheduleRecover`, `_startServer`, `_waitConnected`, `_tryConnectList`, `_smartConnect`, `_forceDisconnect`, `_toggle`.
- Profile/account lifecycle: `_loadProfiles`, `_switchProfile`, `_login`, `_logout`.
- Update lifecycle: `_checkUpdate`, `_startApkDownload`, `_installApkFile`.
- `patch_tv.py` and `patch_signing.py` patch the Android project generated by CI.
- `.github/workflows/build.yml` generates Android files, patches TV/signing setup, builds split release APKs, uploads artifacts, and creates a GitHub Release.
